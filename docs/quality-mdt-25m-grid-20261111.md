# 개선후보 MDT 25m 격자 배경 레이어 (2026-11-11)

## 원본과 데이터 무결성
- 입력: `data/25격자/개포동 MDT.xlsx`, 시트 '개포동 MDT', 날짜 **2026-11-03**.
- 원본: 28,118개의 주파수별 MDT 집계 행, 9,226개 서로 다른 25m POT/GPOT 중심점.
- 위치 기준: `POT_중점 UTMK X/Y` (열 F/G), `POT_중점 LATITUDE/LONGITUDE` (열 H/I). x/y 고유 좌표 차이가 25m인 것을 점검.
- RF 기준: `LTE_MDT_측정 수` (O), `LTE_MDT_RSRP 평균` (P), `Network_LTE EARFCN` (N). 주파수는 475=2.1, 1550=1.8광, 1694=1.8협, 3743=900.
- 동일 격자에 있는 **각 대역의 P열 평균값에 O열 측정 건수를 곱하여 전체 합산하고, 총 측정 건수로 나눠** 통합 평균 RSRP(dBm)를 산출. 이는 서로 다른 주파수를 가중한 참고 평균으로서 개별 주파수의 성능을 대체하지 않음. 마우스 오버로 개별 대역 평균/측정 건수를 확인.
- 공백 격자를 임의 생성하거나 관측 RSRP를 보간하지 않음.
- 배포 전용 산출물: `public/quality-improvement/mdt-grid-25m-v1.json`, `scripts/build-mdt-25m-grid.py`.
- 원본 XLSX 및 기존 CDR/GPS/MDT/RTCP와 후보 클러스터 산출물 변경 없음.

## 지도 표시
- 개선후보 일반/전체화면 지도에 공통으로 표시.
- `전체 기간` 버튼 **바로 왼쪽**에 `25m 격자` 드롭다운을 배치. 선택지는 **Top1, 900, 1.8협, 1.8광, 2.1, 숨김** 총 6개, 초기값 Top1. DBSCAN 및 5개 대안 모델과 전체 화면에서 같은 선택 상태를 공유.
- Top1은 개별 셀 ID가 아니라 **25m 격자별 측정 건수(O열)가 가장 많은 EARFCN**의 RSRP 평균(P열)을 선택하는 기능. 측정 건수가 같으면 900 → 1.8협 → 1.8광 → 2.1 순으로 결정론적 선택. 미측정 주파수는 회색 셀로 표시하고 0건으로 안내. 없던 데이터를 보간하거나 다른 주파수 값으로 대체하지 않음.
- 현재 **화면에 표시되는 후보 원의 안쪽**에 위치하는 격자 중심점만 지도 배경으로 투영. 핵심/전체 후보 필터와 모델 선택 시 자동 갱신.
- 각 25m 셀은 원본 UTMK 중심 좌표를 기준으로 실제 25m 격자 방향을 가까운 동/북쪽 이웃 관측 좌표의 평균 변화량으로 환산한 근사 사각형. 중심점은 원본 LAT/LON 그대로 사용.
- 지도 기존 단말/GPS/MDT 근사/기지국/후보 원보다 낮은 별도 Leaflet Canvas pane(z-index 340)에 채움 불투명도 0.34(측정값) / 0.17(수집 값 없음)로 렌더링. 지도 줌 및 드래그 유지.
- 지도 오른쪽 위 RSRP 범례: >−60 빨강, −60~−70 빨강→주황, −70~−80 주황→노랑, −80~−90 노랑→초록, −90~−100 초록→파랑, −100~−110 파랑→짙은 파랑, <−110 검정, 수집 값 없음 회색. 사용자 제공 범례에 대응.
- 격자 호버: 선택 주파수(Top1에서는 선정 주파수), 해당 RSRP 평균(dBm), **2026-11-03** 원본 날짜, 해당 주파수의 측정 건수, PotID, 다른 대역 RSRP 평균/측정 건수. 셀의 평균값이지 QoE 하락 순간의 RSRP가 아님.
- 원본 2026-11-03 기준 자료는 현재 QoE 후보 선정 기간(2026-10-26~30)과 날짜가 다르며 **참고 배경**으로만 사용. 후보 생성/순위/통화 수/MOS 계산식에 투입 금지.
