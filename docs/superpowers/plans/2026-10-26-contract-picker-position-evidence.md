# 계약 선택 및 위치 추정 근거 복원

사용자 요청: 계약번호 선택이 어렵고, GNSS 좌표가 없을 때의 삼변측량 기능을 찾을 수 없음. 현재 clean `1e2fd66`에서 시작한다.

## 원인과 범위
- 검색어가 비어 있으면 결과가 없고 입력 후에도 40개만 표시된다. 번호를 모르는 분석가는 계약을 탐색하기 어렵다. 현황 표의 계약번호 자체도 일반 텍스트다.
- `normalizeDay()`는 GNSS 없는 시점에 `estimateAdaptive()`를 계속 호출한다. 다만 추정 방법·사용 사이트·시간창·잔차·경고가 정규화 과정에서 사라지고, 기존 상세 추정 컨트롤은 새 화면에 연결되지 않았다.
- 기존 위치 모델과 좌표 결과를 바꾸지 않고 실제 계산 근거를 보존해 표시한다. 새 물리 모델·보정·GNSS 품질 판정은 별도 위치 개선 계획의 범위다.
- 3개 이상 물리 사이트의 MULTILATERATION, 2사이트 가중중심, 단일사이트/근거 부족의 보류를 정확히 구분한다. 2사이트를 삼변측량이라고 표시하지 않는다.

## 구현 및 소유권
- [x] 계약 선택: 빈 검색으로도 열 수 있는 날짜별 계약 목록, 검색·GNSS 없음 필터·페이지 이동·선택을 제공한다. 현재 선택·원본 번호·통화/관측/GNSS 건수를 표시한다. 현황의 계약번호를 눌러 해당 통화 분석으로 이동한다. 기존 붙여넣기 검색과 키보드는 유지한다.
- [x] 근거 전파: `AnalystSample.estimation`에 실제 engine 결과의 method/siteCount/windowSec/usedSites/residual/geometry/jump/warnings를 보존한다. 좌표 보류 시에도 사유를 제공하고 기존 좌표·QoE는 그대로 유지한다.
- [x] 추정 UI: GNSS 우선·좌표 없는 시점 자동 추정을 항상 설명한다. 현재 통화의 GNSS/3+사이트/2사이트/보류 수, 추정 시점 이동, 선택 관측의 방법·근거·경고를 표시한다.
- [x] 지도: `showEstimationEvidence?:boolean`으로 선택 관측의 사용 기지국·연결선·거리 모델 참고 원을 표시한다. 연결선은 고객 경로가 아니며 반경은 검증된 정확도가 아니다. 근거 켜기/끄기가 확대·중심을 초기화하지 않는다.
- [x] 회귀/실제 브라우저/타입/정적 검사/빌드 및 독립 검토를 통과했다. 로컬 커밋에 데이터·실제 고객 캡처는 포함하지 않는다.

### 파일 경계
- Selector agent: 신규 contract-picker와 helper/CSS/검사, analyst-dashboard.tsx 및 shell CSS, quality-overview.tsx의 계약 클릭 동작/검사.
- Evidence agent: lib/analyst/data.ts, 신규 estimation-evidence helper/검사, contract-workspace.tsx/CSS, observation-details.tsx 및 관련 검사.
- Root: 공유 types.ts를 먼저 확정하고, analyst-map.tsx/CSS와 통합 검증·문서를 담당한다.

### 공유 계약
- `AnalystEstimationEvidence`는 기존 method 이름과 물리 사이트별 좌표·ID·RSRP·거리·시간차를 보존한다. `AnalystSample.estimation`은 선택적이다.
- `estimationMethodLabel(method)` helper는 엔진 method를 정직한 한국어 표시명으로 바꾼다. Root 지도에서도 같은 helper를 사용한다.
- `AnalystMap.showEstimationEvidence?:boolean`은 선택한 관측에만 근거 레이어를 추가한다.
- 계약 목록에는 현재 날짜의 SourceDay.callCount/gnssSampleCount/sampleCount를 사용한다. 없는 값은 미제공이며 0으로 만들지 않는다.

## 검증 초점
빈 검색 목록, 앞자리 0, 부분 번호, 날짜/출처 변경, GNSS 없는 계약, 페이지 넘김, 취소·Escape·초점 복귀, 원본 index 시점 이동, 3+/2/1/0사이트의 정직한 구분, 좌표 없는 보류 원인, 지도 근거 레이어와 viewport, 기존 분모·주소·QoE 불변을 확인한다.
