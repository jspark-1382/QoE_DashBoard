# 개선 후보 지역별 AI 분석 및 점검 SOP 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 기존 개선후보에서 후보별 Qwen 분석을 명시적으로 실행하고, 짧은 요약과 상세 분석·SOP 초안·근거 자료를 확인한다.

**Architecture:** 기존 비동기 Qwen 작업 API에 후보 전용 대상을 추가한다. 서버가 현재 후보 산출물과 SQLite 구성 통화를 다시 대조하고 SOP 조건을 선택한다. Qwen은 비식별 집계를 해석하며 구조·근거·숫자·SOP 참조 검증을 통과한 결과만 완료로 공개한다.

**Tech Stack:** React, TypeScript, Node worker_threads, read-only SQLite, 기존 OpenAI 호환 Qwen 클라이언트.

**Spec:** 이 작업의 사용자 명세 “개선 후보 지역별 AI 분석 및 점검 SOP”(2026-11-12).

## Global Constraints

- 한국어 UI, 현재 `.env` 값 유지, 비밀 설정은 서버에서만 사용한다.
- 기존 고객·통화 분석, QoE/MOS/Drop 정책, 군집 알고리즘과 지도 탐색 상태를 보존한다.
- 후보 단순 선택·지도 이동·팝업 탭 변경으로 Qwen을 자동 호출하지 않는다.
- 원본 전체 재생성 없이 현재 후보 산출물과 조회 DB를 사용한다.
- 후보 구성 집단을 지역 전체 분모로 쓰지 않는다. 정상 비교군 미확보는 null/미산정이다.
- 범위 검토 상태는 AI 완료와 독립적이며 SOP는 공식 승인 절차가 아닌 조회용 초안이다.

## Review Focus

- 다른 후보를 선택한 뒤 도착한 응답이 현재 후보로 섞이지 않아야 한다.
- 같은 원본 버전에서도 구성 통화나 산출물 조건이 바뀌면 이전 결과를 재사용하지 않는다.
- 모든 통계와 표본 통계, 위치 종류, MDT 배경 격자와 통화 측정을 구분한다.
- 취소·빈 응답·잘린 응답·잘못된 참조를 정상 완료로 표시하지 않는다.
- 전체화면 지도 위 분석 팝업의 Escape/Tab/포커스가 기존 지도 상태를 변경하지 않는다.
