## 판단과 범위

- 기존 모드의 기능과 수치를 보존하기 위해 개선 기능을 variant에서만 적용했다. 구형QualityOverview 해시는 계속 보호하고, 개선 대상 QualityProposalFour의 파일전체 해시 고정은 동작/집계 비교로 대체했다.
- 이전 독립workspace의 경로 연결은 제거했으며 파일은 이력/참조 검토를 위해 남겨두었다. 해당workspace와 대형report는 실제 개선 화면에서 불러오지 않는다.
- 임의 시간창 후보는 별도 산출물이 필요하다. 미생성 조건은 후보 영역에만 표시하고 기본 현황을 유지한다. 현장/SCAN/외곽 실측·구간MOS·NQI/WING은 원래 계획의 후속 범위다.

## VWorld 배경지도 복구

별도 검증 빌드에 기존 지도 설정이 누락된 것을 확인했다. VWorld 항목만 전달하는 검증된 도우미를 추가하고 다시 빌드했다. 브라우저에서 VWorld 이미지 응답10개·256px 이상 정상 타일10개와 설정 누락 메시지 제거를 확인했다. 기존 키·원본 데이터·화면 구성은 변경하지 않았다.

## 후보 분석 UI 원본 구성 공유

- 개선본이 별도 후보 패널로 원본의 3개 요약 카드·종류 필터·선택 상세·RF 참고·관련 통화·현장 점검 구조를 대체한 것이 차이의 원인이었다.
- 원본의 화면을 CandidateWorkspaceView와 CandidateDetail로 공유했다. 개선본은 범위별 결과를 같은 표시 형식에 연결한다. 원본의 기존 후보 자료와 검증 규칙은 유지한다.
- 개선 자료에 없는 정상 참고 표본·Cell 후보는 미산출, RF 요약값은 미확보로 표시한다. 대표 GNSS를 원본 전체 관측으로 오인하지 않도록 이름을 구분한다. 검증일 없는 범위는 별도 검증일 없음으로 표시한다.
- 후보 요약의 체감 고객 수는 후보 간 중복 고객을 제거한 실제 고객 수로 출력했다. 선택 후보 Drop은 발견 구성 통화의 SIP 사유에서 계산한다.
- 품질 개선 17개·고객/지도33개·품질 탭15개 검사, TypeScript, 수정 파일 lint, 별도 빌드 통과.
- 브라우저에서 원본/개선 모두 카드3개·필터3개와 동일 상세 영역, 후보 선택과 Cell/전체 전환을 확인했다. VWorld 정상 타일 원본15개/개선23개, 화면 오류0건. 10월30일 저품질288건도 다시 확인했다.
- 비교 화면 캡처는 outputs/quality-revision-qa/candidate-current.png 및 candidate-improvement1.png에 저장했다.

## 후보 분석 전체 화면 비교 수정

- 사용자가 제공한 전체 화면 비교에서 개선본에만 상단 현황 지표·수집 현황·차트가 남아 후보 분석 전체가 아래로 밀리는 오류를 확인했다. 앞선 검증은 후보 영역 내부만 비교해 이 차이를 놓쳤다.
- 후보 분석에서는 원본과 개선본 모두 동일하게 현황 지표·차트·수집 현황을 표시하지 않는다. 분석 조건 바로 아래 후보 요약 3개와 지도/목록이 나온다. 기존 현황으로 전환하면 현황 지표·차트가 다시 표시된다.
- 개선 후보의 관련 통화 조사를 명시적으로 선택한 경우에만 통화 조사 표를 표시한다. 표를 닫으면 후보 분석 기본 구성으로 돌아간다.
- 전체 화면 회귀 검사를 scripts/tests/quality-improvement-layout.browser.cjs에 추가했다. 수정 전 개선본에서만 현황 지표가 나타나 실패하는 것을 재현했다. 후보 부분 캡처 대신 전체 페이지의 지도 위치·크기와 표시 영역을 비교한다.
- 2560/1440/680px에서 두 모드의 후보 시작 위치와 지도 x/y/폭/높이가 모두 일치했다. 관련 통화 조사·기존 현황 복귀 및 20회 연속 모드 전환 검사에서 화면 오류0건을 확인했다.
- 빠른 전환 검사에서 발견한 Leaflet 초기 확대 지연 콜백과 Canvas 재그리기 콜백의 지도 제거 후 실행 문제는 후보 지도의 초기 범위를 즉시 적용하고 소규모 후보 레이어에 SVG를 사용해 해결했다. VWorld 배경지도와 일반 현황 지도 렌더링 설정은 유지한다.
- TypeScript·빌드와 품질 개선17개/품질 탭15개/고객 지도33개 검사를 통과했다. 전체 화면 캡처는 candidate-fullpage-{current,improvement1}-{2560,1440,680}.png로 저장했다.
