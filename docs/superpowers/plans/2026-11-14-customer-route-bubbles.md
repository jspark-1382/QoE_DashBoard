# Customer route overlap bubbles

**Goal:** Group overlapping customer-route location circles at the current map zoom; split them as the user zooms in. Retain all original observations, counts, evidence types, selected-call focus and chronological reference links.

**Design:** Keep existing orange BYE-reference and teal GPS colors. A grouped bubble shows poor/total calls plus its number of locations. Mixed-source groups are explicitly identified. Clicking a group zooms to its recorded locations; a details action exposes all locations/calls. At maximum zoom the existing same-coordinate separation and original call details remain available. Bubble centers are visual summaries, never new measured positions.

**Architecture:** A pure helper clusters projected screen coordinates, with deterministic membership and unchanged source records. Only the selected-customer route overlay uses this helper; TOP10, administrative, cell and GPS-only map modes retain their existing behavior. Existing zoom events redraw groups without refitting the selected customer.
