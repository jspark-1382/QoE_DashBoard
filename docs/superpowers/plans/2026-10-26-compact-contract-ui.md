# Compact contract analysis implementation plan

> **For agentic workers:** Use subagent-driven-development for independent units and verify the integrated screen before committing.

**Goal:** 사용자 첨부를 구현 기준으로 계약 분석을 간결한 3단 화면으로 정리한다.
**Architecture:** 기존 React/CSS modules/Leaflet와 선택·조회 경로를 유지한다. 상단 검색과 일자/출처는 한 줄, 왼쪽 통화 표, 가운데 지도와 RSRP/SINR, 오른쪽 선택 관측으로 구성한다. 모델 설명과 조사 도구는 접어 둔다.
**Spec:** 2026-10-26 사용자 첨부 이미지 및 기존 `../specs/2026-10-24-qoe-analyst-ui-design.md`의 데이터 의미/원본 보존 조건.

## Global constraints
- 기존 위치 계산식·QoE·분모·고객 좌표를 변경하지 않는다. 원본 계약번호 문자열과 검색/목록 선택을 유지한다.
- GNSS 유무와 MDT 유무는 다르다. MDT/무선 추정 통화를 CDR 전용으로 분류하지 않는다.
- CDR 시작/종료 기지국 좌표는 고객 위치나 이동 경로로 그리지 않는다. Cell-ID 없거나 매칭되지 않으면 미제공을 표시한다.
- 3개 이상 삼변·다변측량 / 2개 가중중심 / 단일 근거 위치 보류 구분과 실제 계산 근거는 접힌 영역에서도 유지한다.
- 주요 3단은 1366px부터 유지하며 작은 화면에서는 순서대로 쌓인다. 가로 넘침을 만들지 않는다.
- 데이터·고객 캡처는 Git에서 제외한다. 새 의존성은 추가하지 않는다.

## 완료 기록
- 관측·시간축은 전용 CSS로 분리했고 원본 값·분모·관측 index·공백 규칙을 유지했다. 기본 RSRP/SINR 이외의 조사 도구와 계산 진단은 닫힌 영역에 보존했다.
- 시작/종료 Cell-ID 문자열을 변환/정규화/화면까지 전달했다. 현재 TXT에 Cell-ID 매핑이 없음을 확인해 CDR 전용 지도 좌표는 생성하지 않았다. GNSS 0건 MDT와 CDR만 있는 통화는 별도로 검증했다.
- 실제 데이터를 EPSG:5179로 재생성했다. 새 revision `3562cf5fd16d5a56f5f0`: 고객 10,250, 통화 25,548, 이벤트 596,865, 평가 가능 23,085, 평가 불가 2,463, 저품질 2,583으로 기존 집계와 일치한다. 생성 데이터는 Git에 넣지 않았다.
- 독립 검토에서 검색/뒤로 가기의 이전 검색어, 넓은 SVG 차트 클릭 좌표, 자정 통화 시간 표시의 세 문제를 확인해 수정했다. SVG/자정 표시는 RED→GREEN 회귀를 추가했고 현재 계약 검색은 실제 브라우저에서 B→뒤로 A→찾기 순서를 확인했다. 세 항목의 재검토 결과 잔여 문제 없음.
- `test:analyst`, 타입 검사, 화면 정적 검사, 위치 추정 15개 그룹, Python 49개 검사, 실제 데이터 집계 회귀를 통과했다. 최종 프로덕션 빌드 성공. 기존 브라우저 회귀 스크립트는 새 레이블/접힘 동작에 맞춰 갱신하고 구문을 확인했다.
- CUA 실제 브라우저에서 1920/1366의 3단·가로 넘침 없음, 390의 순서대로 쌓임, 계약 목록/검색/뒤로/찾기, MDT 필터, CDR Cell-ID와 임의 지도 없음, GNSS 선택, 2사이트 근거, 차트 선택, 상세 기본 접힘을 모두 확인했다. 결과 JSON과 실제 고객 캡처는 `outputs/analyst-ui/`에만 저장했다.
- 새로고침 시 오래 실행된 개발 서버의 내부 ALS 재귀 오류를 확인했고, 작업 폴더와 포트를 검증한 뒤 해당 서버만 같은 설정으로 재시작해 복구했다. 종속 라이브러리 소스는 수정하지 않았다.
