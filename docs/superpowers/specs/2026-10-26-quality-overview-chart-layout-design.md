# 품질 현황 그래프 재배치안

상태: 후속 승인에 따라 구현. 최초 요청은 배치 계획·이미지 시안이었고, 사용자가 '제안한 배치는 유지하고 그래프 모양·색상을 원본처럼 구현'으로 범위를 확정했다. 요약 띠와 배치를 유지하고 원본의 분포·색상·아이콘·미니 막대를 실제 집계로 연결했다.

## 배치

1. 상단 필터 아래에 하나의 요약 띠를 둔다. 전체/평가 가능 통화, 평균 점수, 저품질 통화·비율, 비정상 종료, 영향 계약을 세로 구분선으로 나눈다. 각 카드의 아이콘·작은 추이 차트는 생략한다. 분석 계약 수는 범위 설명에 표시한다.
2. 그 아래 높이 약 180~200px의 그래프 행을 둔다. 왼쪽 점수 분포 32%, 가운데 시간대별 저품질 44%, 오른쪽 고객 체감 24%로 배치한다. 점수가 어떻게 퍼지는지, 언제 나빠지는지, 누가 반복적으로 경험하는지를 같은 높이에서 읽게 한다.
3. 지도와 조사할 구역 순위는 다음 행에 약 70:30으로 유지한다. 지도 높이는 약 320~360px이며 기본 60m 격자와 평가 가능 통화를 분모로 하는 지역 비율을 유지한다.
4. 통화 목록은 맨 아래 전체 폭으로 둔다. 선택한 점수 구간·시간대·체감 집단·구역은 목록 위의 해제 가능한 조건으로 표시하고 계약·통화 분석으로 연결한다.

## 그래프 표현

- 점수 분포: 히스토그램과 간결한 구성비 막대. 미평가 통화는 분포에서 제외하고 별도로 건수를 표시한다. MDT는 QoE 1~5와 현재 저품질 기준 2.5만 사용한다. 실제 MOS가 제공되는 실측 모드에서는 MOS 양호 4.0 이상 / 보통 3.5 이상~4.0 미만 / 불량 3.5 미만으로 전환한다. MOS 값을 MDT QoE로 대신하지 않는다.
- 시간대별: 현재 건수/비율 전환을 유지하는 하나의 막대 차트. 상단 요약의 추이는 이 차트로 통합하고, 체감 품질 카드는 원본 형태의 미니 막대를 추가한다. 미니 막대는 선택 일자의 시간 내 조건 충족 계약 수이며 시간 간 중복될 수 있다. 비교 기간이 없을 때 전일 대비 화살표를 만들지 않는다.
- 고객 체감: 저품질 1회 이상 / 2회 이상 반복 / 2회 이상 연속의 가로 막대 3개. 서로 포함될 수 있는 집단이므로 누적 막대나 합계로 표현하지 않는다. 사람 수가 확정되지 않은 현재 데이터는 서비스 계약 단위로 집계하고 단위를 계약으로 표시한다.
- 비정상 종료: 상단 수치로만 표시하고 원인별 차트는 상세에 둔다. 코드 사전과 판정 규칙이 확인되기 전에는 0이나 추정 비율 대신 집계 기준 확인 상태를 표시한다.

## 데이터와 상호작용

- 현재 overview에는 QoE, 전체/평가/미평가/저품질 통화, 영향 계약, 시간대/격자 집계가 있다. 평균 QoE·분포·반복 계약은 기존 고유 통화 집계에서 계산할 수 있다.
- MOS, 종료 판정용 필드, 날짜를 포함한 통화 시작 시각은 상세에만 있거나 현재 overview에서 빠진다. 전체 고객 상세를 브라우저에서 일괄 내려받지 않고 사전 생성 집계를 확장한다.
- 비정상 종료는 normal/abnormal/unknown으로 분류한다. 판정 가능한 통화를 비율 분모로 삼고 미분류 건수를 함께 보인다. 코드가 존재한다는 이유만으로 비정상으로 간주하지 않는다.
- 반복은 분석 범위 안에서 저품질 통화 2건 이상이다. 연속은 고객별 전체 통화를 실제 시작 시각 순으로 판정해야 한다. 제안 기준은 미평가 통화가 있으면 연속을 이어 붙이지 않고, 시각이 불명확하거나 동시 통화 순서를 정할 수 없으면 연속 판정을 보류하는 것이다.
- 상단 요약과 그래프의 기준은 일자·시간 범위·출처다. 그래프 클릭은 조사 조건이며 상단 전체 집계를 바꾸지 않는다. 지역/시간/점수/집단 선택은 통화 목록에 교차 적용하고 모든 조건을 표시한다.
- 평균은 유효한 통화별 점수의 산술 평균으로 정의한다. 관측 샘플 수로 가중하지 않는다. MOS로 지표를 바꾸는 경우 평균·분포·저품질 정의를 함께 전환하고 QoE와 이름·분모를 혼용하지 않는다.

## 구현 순서

1. 기존 집계로 요약 띠, QoE 분포, 시간대 차트, 영향/반복 계약을 구성한다.
2. MOS와 종료 분류를 사전 집계에 추가하고 제공 가능한 데이터에서만 활성화한다.
3. 날짜를 포함한 통화 순서와 연속 판정 규칙을 확정한 후 연속 불량을 연결한다.
4. 기존 전체 분모·위치 없는 저품질·구역 중복·필터 복원·계약 분석 이동을 회귀 검증한다.

## 시안과 반응형

시안은 첨부의 예시 수치와 설명용 수치를 사용하며 실제 조회 결과가 아니다. 구현 화면은 실제 집계를 사용한다. 비정상 종료는 분류 기준 미설정, 연속 불량은 통화 순서가 불명확하면 미제공으로 표시한다. 1366px 이상에서 세 그래프를 한 행에 유지하고, 좁은 화면은 두 그래프+체감 전체 폭, 모바일은 순서대로 쌓는다. 지도와 목록의 조사 기능은 유지한다. 상세 구현·검증 기록은 [원본 스타일 구현 계획](../plans/2026-10-26-quality-overview-original-charts.md)에 남긴다.
