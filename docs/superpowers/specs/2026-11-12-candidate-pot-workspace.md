# 후보 POT 조사 화면 설계

사용자 승인: 2026-11-12 대화의 UI 이미지와 "지금처럼 개발" 지시. 이후 "AI가 선택한 원인 빼고는 안 보여야 한다"는 사용자 수정 요구를 우선 적용한다.

## 화면
- 기존 후보 분석 팝업을 넓게 쓰고, 상단 AI 입력·응답 확인과 닫기를 유지한다.
- 주파수·용량 부족 / 셀 중첩·간섭 / 커버리지 부족 / 셀·주파수 전환 / 장비·전송·단말 이상 다섯 분류는 내부 AI 응답 계약으로 사용한다. 상단에는 검증된 AI가 실제 선정한 원인만 표시한다. 한 개면 선택 버튼 없이 결과를 열고, 여러 개면 실제 결과 사이에서만 이동한다.
- 왼쪽 실제 25m MDT 격자 지도, 오른쪽 선택 POT의 문제 → 추정 원인 → 확인·개선.
- 첫 선정 원인의 POT·날짜·대역을 자동 선택한다. 추가로 선정된 대상 사이의 이동, MDT·AI 선정 POT·기지국 표시 토글, 근거 펼치기를 지원한다. 사용자가 다섯 분류와 모든 POT/대역을 일일이 조사하는 흐름을 요구하지 않는다.
- 분석 대기·실패·이전 버전 결과·선정 원인 없음 상태에서는 임의 원인과 대상 또는 대체 규칙 분석을 만들지 않는다.
- 지도와 내용은 같은 POT·날짜·대역을 사용하며 후보 또는 조건이 바뀌면 이전 응답은 사용하지 않는다.

## 데이터와 표현
- 후보 반경의 모든 POT를 읽기 전용 context API로 제공하고 모든 유효 POT×날짜×대역×EARFCN과 인접 관계를 AI 입력에 포함한다. 상위6 잘라내기는 제거한다. 입력 한도 초과는 명시적으로 실패시키며 일부를 조용히 누락하지 않는다.
- 지도에서는 AI가 선정한 POT만 결과 이동에 사용하고 나머지 격자는 배경 관측으로 표시한다.
- 원본 측정 P/Q와 기준이하 비율, 날짜별·대역별 값을 유지. 결측을 0/정상으로 취급하지 않는다.
- 오른쪽 3단계는 실제 Qwen hypothesis의 title/reason, 연결된 원본 target 지표, target별 검증된 SOP를 표시한다. 클라이언트 규칙 계산을 AI 발화로 대체하지 않는다. Qwen 원문과 System/User는 기존 inspector에 그대로 유지한다.
- category/target/evidence/SOP 연결, 현재 prompt/SOP 버전, 대상별 SOP 및 관측 근거를 서버와 클라이언트에서 검사한다. 검증되지 않은 모델 응답은 결과 화면에 표시하지 않는다.
- 추정 원인은 근거가 있는 경우만 의심으로, 부족하면 판단 보류로 표시한다. 약전계만으로 투자/PCI충돌/HO/무선외장애를 확정하지 않는다.
- 기지국은 실제 등록좌표. 후보 통화 BYE Cell 유일 매칭/복수 등록/주변 참고를 구분한다. POT 책임기지국으로 자동 단정하지 않는다.
- 이미지에 있던 기지국 A/B 및 지명 예시를 실데이터로 하드코딩하지 않는다.
- 기존 고객분석, 군집화, 원본 Excel 및 기존 환경설정 값은 보존한다. 실제 검증에서 확인한 응답 잘림은 후보 전용 QWEN_CANDIDATE_EXTRA_BODY_JSON 옵션을 추가해 해결한다. 이 추가 옵션은 후보 요청·진단·캐시 키에만 반영한다.
