# 고객 선택 패널과 지도 전체 화면

품질 현황 상단 오른쪽에 원본 서비스 고객번호 검색과 고객 목록 버튼을 배치했다. 기존 데이터 출처·평가 지표·저품질 기준은 간단한 설명으로 묶었다.

## 고객 선택

- 고객번호 전체 또는 일부를 입력하고 찾기/Enter를 누르면 오른쪽 선택 패널이 열린다. 고객 목록은 전체 목록으로 연다.
- 목록 범위는 현재 조회 기간과 시작·종료 시간이다. 지도 세부 필터와 독립적으로 집계하며 위치 미확보 고객도 포함한다.
- 전체 / 불량 1건 이상 / 반복 불량 2건 이상 필터, 25명 단위 페이지 이동을 지원한다.
- 원본 고객번호와 앞자리 0을 유지한다. 통화 수·유효 MOS 3 미만 수·위치 연결 수는 통화 ID를 중복 제거해 계산한다.
- 고객은 체크박스로 여러 명 선택한다. 검색·불량 조건·페이지를 바꿔도 선택 초안을 유지한다. 현재 페이지 일괄 선택과 선택 해제를 지원한다.
- 아래 고정 요약에서 선택 인원과 통화·불량·위치 연결·미확인 합계를 확인하고 '선택 고객 N명 적용'을 누른다. 적용 후 지표·분포·시간대·고객 체감품질·지도·지역 순위·통화 목록·CSV를 선택한 고객 기준으로 조회한다. 지도에는 선택한 MOS 등급과 위치 근거가 있는 통화만 표시한다.
- 적용 시 기존 지역·시간대·고객군·MOS 등급·통화 상세 등 세부 탐색은 초기화하고 선택 고객의 지도 범위로 맞춘다. 시작·종료 날짜와 시간은 유지한다. 날짜·시간 변경 후에도 고객 선택은 유지하며 해당 범위에 통화가 없으면 0건으로 표시한다.
- 패널을 다시 열면 적용한 고객을 선택한 상태로 표시한다. 닫기/Esc는 미적용 변경을 취소한다. 한 명만 선택했을 때는 '고객·통화 분석 열기'로 해당 고객 최근 통화에 바로 이동할 수도 있다.
- 상단 '전체 고객으로 보기' 또는 패널의 전체 고객 조회로 고객 필터를 해제한다. 전체 필터 초기화도 고객 선택을 해제한다.
- 개선 후보 분석은 전체 고객으로 미리 계산된 보고서이고 전체 고객 멤버십이 포함되어 있지 않다. 부분 고객 집계로 오인하지 않도록 고객 필터 적용 중에는 진입을 제한하고 해제 방법을 표시한다.
- 고객 검색을 위해 모든 상세 파티션을 불러오지 않고 이미 확보한 요약과 메타데이터를 사용한다.
- 닫기, Esc, 배경 클릭으로 닫으며 원래 검색 입력/버튼으로 초점을 돌린다.

## 지도 전체 화면

품질 현황 지도와 개선 후보 지도에 '지도 전체 화면' 버튼을 추가했다. 지도 패널이 브라우저 영역을 채우고, '전체 화면 닫기' 또는 Esc로 돌아온다.

기존 지도 인스턴스를 유지하므로 확대/이동 위치와 선택 조건이 유지된다. 헤더·위치 근거 필터·범례를 확대 화면에서도 제공한다. Leaflet의 기존 크기 관찰 기능으로 지도를 새 영역에 맞춘다. 확대 지도에서 통화 상세를 열면 상세창이 키보드 제어를 맡고, 상세창을 닫은 뒤 확대 지도로 돌아온다.

기존 지역 선택 합계 오류도 수정했다. 선택 지역의 실제 지도 통화 수와 '선택 등급 위치 근거' 합계를 일치시킨다. 전체 지역 순위는 유지해 다른 지역을 선택할 수 있다.

원본 측정 데이터·MOS 계산·통화 식별자·기지국 인벤토리는 변경하지 않는다. `npm run test:customer-map`으로 관련 회귀 검증을 실행한다.
