# MDT 기지국 기반 위치 후보 추정 POC

구현 및 검증: 2026-09-08. GPS 위치 계산이나 삼변측량이 아니다. 표시 좌표는 경험적 후보 영역의 대표점이며, 신뢰도는 정확도나 확률이 아니다.

## 1. 추가·수정 파일

- 추가: `lib/location-estimation/{types,config,rsrp-distance,frequency-adjustment,uncertainty,geo,master,candidate-grid,trajectory,cell-transition,confidence,index}.ts`
- 추가: `components/executive/mdt-location-map.tsx`, `scripts/test-location-estimation.cjs`, 본 문서.
- 수정: `scripts/extract_mdt_data.py`, `lib/executive/{types,selectors}.ts`, `components/executive/{executive-dashboard,qoe-time-chart}.tsx`, `app/globals.css`.
- 추출 결과 `public/mdt-data.json`은 기존 방식대로 생성되며 Git 제외 대상이다. 원본 데이터를 수정하지 않는다.

## 2. RSRP → Radius

`config.ts`의 시뮬레이션 기준을 선형 보간한다. 물리거리 정답으로 검증된 표가 아니다.

| RSRP dBm | 반경 m |
| --- | --- |
| ≥ -70 | 100 |
| -75 | 150 |
| -80 | 250 |
| -85 | 400 |
| -90 | 650 |
| -95 | 1000 |
| -100 | 1500 |
| -105 | 2200 |
| -110 | 3000 |
| ≤ -115 | 4000 |

-82.5는 325m. -110 아래는 갑작스러운 변화 대신 -115까지 4000m로 부드럽게 증가한다. `calibrationMode: default / site-specific`과 사이트별 표 교체 지점이 있다. 사이트별 표가 없으면 임의 기본값으로 대체하지 않고 결과를 반환하지 않는다.

## 3. Frequency

원본의 1550/1694/3743에는 단위 정보가 없어 기본은 **미확인, 배수 1.0**이다. 숫자 크기로 MHz를 추론하지 않는다. UI에서 확인된 MHz 또는 LTE EARFCN을 명시적으로 선택할 수 있다. NR-ARFCN은 미지원이며 보정하지 않는다.

확인된 MHz 기준 <1000: ×1.25, 1000–2100: ×1.0, >2100: ×0.8. LTE는 지원 DL Band 1–8 표로 변환하며 3743은 Band 8의 954.3MHz가 된다. 변환식 참고: [ETSI TS 136 101](https://etsi.org/deliver/etsi_ts/136100_136199/136101/09.05.00_60/ts_136101v090500p.pdf). 이 변환이 원본의 형식을 확인해 주는 것은 아니다.

## 4. Tx Power

TOTAL에만 43dBm 대비 상대 배수 `10^((power-43)/40)`를 적용하며 0.85–1.15로 제한한다. TOTAL에서 RSRP를 빼지 않는다. 현재 Master는 모두 43dBm이므로 배수 1.0이다. RS는 별도 확장을 위해 구분하되 현재 물리모델을 적용하지 않는다.

## 5. Uncertainty

기본 ±40%. SINR ≥15:25%, ≥5:35%, ≥0:45%, <0:60%. RSRQ ≤-15이면 10%p, ≤-20이면 15%p 추가하고 최대 75%로 제한한다. 내측/외측은 보정 반경 × (1∓불확실성)이다. 모두 Config에서 변경 가능하다.

## 6. Candidate Position

현재 Annulus 안에 기본 100m 격자를 만들고 경험적 반경에 가까울수록 점수를 높인다. 계산량이 커지면 격자를 적응적으로 넓혀 24,000점 수준으로 제한한다. 최고 점수의 80% 이상 후보를 최종 영역으로 사용한다. 가중 중심이 고리의 빈 내부에 놓일 수 있으므로 대표점은 지원되는 후보로 투영한다. 면적은 격자 근사치이며 확률 면적이 아니다.

## 7. Time Continuity

최근 1/5/8개를 선택한다. 최근 관측부터 0.8의 지수 감쇠를 적용한다. 다른 익명화 가입자 스트림을 연결하지 않으며 120초 초과 공백 또는 연결 불가능한 관측에서 이력을 끊는다. 보행 2, 차량 30, 미확인 40m/s 상한을 넘는 이동에는 부드러운 페널티를 준다. 후보 분포와 대표점 이동 모두 고려하지만 물리적으로 불가능한 입력을 사실로 교정하는 기능은 아니다.

## 8. Cell Transition

같은 스트림의 Cell 변경을 찾고 이전/현재 반경의 겹침 또는 시간에 따른 이동 허용 범위에 가점을 준다. A 약화·B 강화 추세가 충분하면 추가 가점이 있다. 미래 데이터를 미리 사용하지 않으므로 전환 직후에는 강화 추세 근거가 부족할 수 있다. 두 기지국과 기준선, 노란 경계 후보를 표시한다. 기준선은 고객 이동 경로가 아니다.

## 9. Confidence

단일 기지국은 LOW이며 방향을 알 수 없다고 표시한다. MEDIUM은 충분한 이력, 전환, 후보 영역 및 일관성을 요구한다. HIGH는 8개 이상 이력, 서로 다른 기지국 3개 이상, 작은 후보 면적(≤0.15km²), SINR ≥15 및 높은 일관성 등 엄격한 조건을 요구한다. 가상 기지국이나 주파수 미확인 상태에서는 HIGH가 나오지 않는다. 같은 기지국의 여러 Cell을 독립된 위치 근거로 세지 않는다.

## 10. 지도 및 선택 연동

기지국 Marker, 경험적 거리 점선 원, 내·외측 원, 내부가 빈 파란 Annulus, 청록 후보 격자, 노란 전환 후보, 추정 대표점과 후보 포괄 범위를 표시한다. 보라 점선은 대표점 이력이다. Sample/Cell 변경 드롭다운과 차트 선택이 지도에 연결되며 지도 추정점 클릭은 해당 Sample을 선택한다. 상세 패널에 좌표, 거리, 반경, 무선값, 보정 배수, 신뢰도 근거를 표시한다.

## 11. 실제/가상 및 Join

현재 Master 10개 모두 가상이며 Marker와 상세에 가상 기지국 배지를 표시한다. 페이지 하단에 “기지국 좌표와 위치 추정 결과는 POC용 가상 데이터가 포함될 수 있습니다.”를 표시한다.

365개 무선 이벤트 중 293개 정확한 Cell/기지국/주파수 연결, 18개 유일한 기지국+주파수 대체 연결, 54개 미연결이다. 대체 연결은 경고하며 모호하거나 다른 주파수의 Cell에 강제 연결하지 않는다. 미연결 Sample은 위치를 만들지 않고 안내한다.

## 12. 검증

- 자동 테스트 11개 그룹 통과: 보간/단조성, 주파수, Tx 제한, 불확실성, 엄격한 Join, 고리 내부 제외, 이동 페널티, 전환, 빈 데이터/스트림 분리, 신뢰도, 실제 로컬 데이터 연결.
- 2km/5초 페널티와 50m/10초 유지 확인. 8개 Sample 로컬 계산 약 14ms(환경 의존).
- `npm run build` 통과. 전체 TypeScript 검사에는 기존 `app/engineering/page.tsx`의 별도 오류 3개가 남아 있다.
- 브라우저 1920×1080에서 실제 지도와 Annulus, 가상 배지, 전환 후보, 상세 패널 확인.
- 같은 기지국 -94→-89dBm 선택 시 930→600m로 반경 감소 확인.
- 3743 Sample: 미확인 720m → 명시적 LTE EARFCN 선택 900m(×1.25) 확인 후 미확인으로 복구.
- SINR -3dB Sample의 ±60%, SINR 8dB Sample의 ±35% 표시 확인.
- Master 미연결 Sample 선택 시 오류 대신 안내 확인.
- Cell 변경 09:41:22 선택 시 두 가상 기지국/노란 후보/8개 이력/MEDIUM 확인.
- 지도 확대 후 Annulus의 빈 내부, 거리 원, 후보 격자 유지 확인.
- 빈 데이터 및 비현실적 이동은 자동 테스트로 확인했다. 실제 GPS와 비교하는 현장 정확도 검증은 하지 않았다.

## 13. 한계와 Calibration

방위각, 실제 RS Power, 동시 Neighbor 전체, 실측 손실 모델이 없어 방향과 정확한 위치는 식별할 수 없다. 단일 Cell 대표점 방향은 임의성이 있으며 후보 전체를 함께 봐야 한다. 불연속 MDT 관측 사이 선은 실제 경로가 아니다. 가상 좌표와 경험적 표를 사용하므로 현장 정확도를 주장할 수 없다. 상한/페널티는 불가능한 점프를 억제할 뿐 항상 없애지는 않는다. 격자 크기와 후보 임계값에 면적이 달라진다.

GPS 포함 실측 데이터가 확보되면 독립적인 검증셋으로 사이트별 RSRP–거리 표를 보정하고 `SITE_CALIBRATION_TABLES`를 교체할 수 있다. 현재는 Calibration 학습 파이프라인이나 실측 정확도 수치가 없다. 임의 pathloss_n/indoor_loss_db는 사용하지 않는다.
