# 추가 MDT_New 파일 UI 반영

기존 개포동 SIP CDR·MDT 2개와 추가 도곡·대치·일원·수서 SIP CDR 5개·MDT 1개를 함께 반영했다. 분석 기간은 실제 CDR START TIME 기준 2026-10-26~30이다. 활성 리비전은 `da0b8405340fe0ea2459`다.

| 항목 | 반영 결과 |
| --- | ---: |
| 원본 파일 | 8개 |
| 원본 CDR 행 | 1,490,299 |
| 기간 밖 제외 | 246 |
| 파일 간 중복 통화 제외 | 20 |
| 전체 통화 | 1,490,033 |
| 고객 | 268,182 |
| QoE 평가 가능 | 1,088,738 |
| 저품질 통화 | 9,315 |
| 저품질 경험 고객 | 7,562 |
| SIP Drop | 2,609 |
| 원본 MDT 행 | 711,196 |
| 파일 간 중복 MDT 이벤트 제외 | 2,201 |
| MDT 유일 연결 CDR | 10,115 |

점수는 기존 SIP CDR `140. RTCP MOS(v5)`와 SIP Drop 감점 기준을 유지한다. 추가 MDT에 없는 `rtcp_mos`를 임의 생성하지 않는다. MDT는 계약·시간의 유일 연결을 통과한 실제 관측만 사용하고, GNSS와 BYE 기지국 참고 위치를 구분한다. 원본 Excel은 수정하지 않았다.

날짜별 품질현황, 고객 선별, 고객 통화 상세, GPS 관련 기지국, 삼각 측량 참고 자료, 기간별 개선후보·모델·RF 자료를 같은 원본 버전으로 다시 생성했다. `npm run data:all`은 관련 자료 전체를 생성·대조한 뒤 반영하며, 입력과 처리 코드가 같으면 재생성을 건너뛴다.

원본 파일 8개와 기지국 인벤토리 2개의 내용으로 활성 리비전을 재계산해 일치를 확인했다. 기존 회귀 396개, 최신 자료·fixture 규칙 2개, Python fixture 25개와 타입 검사·앱 빌드가 통과했다. 실제 브라우저에서 전체 집계, TOP10 10명의 경로, 6개 알고리즘, 추가 지역 후보와 신규 고객의 GNSS 9개·통화 상세 지도를 확인했다. QA 결과와 화면은 `outputs/mdt-expanded/ui-qa`에 있다.
