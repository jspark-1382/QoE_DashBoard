## MOS 평가 기준

- 불량: `1.0 <= MOS < 3.0`
- 주의: `3.0 <= MOS < 3.5`
- 양호: `3.5 <= MOS <= 5.0`
- 미평가: 원본 `_`, null, NaN, 허용 범위를 벗어난 값

분모는 **MOS가 유효한 CDR 통화 건수**입니다. `RTCP MOS(v5)` 값은 수정하지 않고 `mosV5Original`에 유지합니다. `qoe`는 화면과 기존 집계 코드의 호환 필드이지만 값은 **원본 MOS(v5)**와 동일하며 무선 품질 지표로 계산한 이전 QoE가 아닙니다. CDR 원본 MOS가 없으면 이 필드도 null입니다.

MOS 알고리즘 개선 시 `mosImproved`와 `mosAlgorithmVersion`을 추가하고, 독립 검증 자료를 확보한 다음 버전별 비교를 구현합니다. 기존 원본값은 덮어쓰지 않습니다.

## 데이터 결합과 해석

CDR의 E2 서비스계약번호와 MDT의 `svc_cont_id`를 먼저 일치시킨 뒤, 통화 시작시각 ±30초 범위에서 후보를 생성합니다. **CDR와 MDT가 상호 일대일인 경우에만** 연계하며 다중 후보·미연결은 샘플을 붙이지 않습니다.

이는 시간 기준 **잠정 매칭**입니다. 반드시 IMS/통화 구분자의 포맷 대응, 시작·종료 Cell-ID 매핑 등을 검토하기 전까지 확정적인 통화 동일성 증거로 간주하지 않습니다. 결과 보고서와 UI에서 '시간 기준 단독 후보'로 표시합니다.

### 2026-11-03 고객·통화 지도 출처 구분 및 통화 시간 개선

고객·통화 분석의 통화 목록에서는 원본 소수 초를 화면에 그대로 노출하지 않고 1초 단위 반올림(분:초, 1시간 이상은 시:분:초)으로 표시합니다. 원본 소수 초 데이터와 계산 값은 변경하지 않습니다. 표시 시간 셀의 툴팁에는 원본 값을 소수 셋째 자리까지 확인할 수 있습니다.

고객·통화 지도에서 위치 근거를 고정된 색상·모양으로 구분합니다: GNSS 관측=청록 원, 다중 RU 무선 추정=보라 마름모, 보간 추정=주황 마름모, 기지국=회색 삼각형. 품질 선택 지표의 기준 미달은 빨간 테두리로 구분합니다. 다른 행정동·기존 대시보드 지도 색상은 변경하지 않습니다. 선택 통화의 GNSS/무선 추정/보간/기지국 건수를 지도 앞에서 보여주고, 선택 관측 근거 패널에도 관측 또는 추정 여부를 함께 표시합니다. GNSS 관측이 0건이면 고객 위치는 실측이 아닌 계산된 추정 좌표임을 경고합니다.
