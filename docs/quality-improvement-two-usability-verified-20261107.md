# 개선 2안 후보 분석 UI 재설계·독립 검증 기록

## 사용자 문제 제기
기존 화면은 오른쪽의 후보 목록과 고객 증거가 하나의 제한된 높이 안에서 겹치거나 잘리고, “중복 위치 1”, “고객 A/B/C”, “반복 저품질 고객”이 무엇을 의미하는지 모호했다. 지도 선택과 오른쪽 요약의 상관관계가 전달되지 않았다. 기본 빨간 강조 테두리가 실제 서비스 UI를 더 복잡하게 만들었다.

## 개편 UI
- 개선 2안에만 별도 후보 분석 컴포넌트: `quality-two-candidate-workspace.tsx` 및 CSS.
- 상단 3개: **저품질 영향 고객**, **조사 후보 지역**, **새 고객 재관측 지역**. 수집된 사람 수와 같은 고객의 반복 저MOS를 혼동하지 않음.
- 왼쪽: 크게 확보한 조사 후보 지도, 선택 후보 노랑, 다른 후보 회색. GNSS/검증일/엄격 3-Site 출처 범례. 지도 전체화면, ESC 종료, 줌 유지.
- 오른쪽: **조사 후보 지역 목록 → 선택 지역 요약 → 고객별 통화 → 상세 원본 근거 펼치기** 순서. 고정 높이에 목록/고객/근거를 밀어 넣는 기존 스크롤 구조 대신 문서 흐름을 활용.
- 후보별 별도 관측일, 고유 고객 수, 통화 수, 검증일 신규 고객 수, GNSS/3-Site 통화 수 표시.
- 원본 행정동 경계 MultiPolygon의 point-in-polygon으로 후보 중심이 포함되는 행정동명을 가져옴. 미확정 위치는 추측하지 않음.
- 미확정 조사 순위는 “범위 검토 필요”로 표시. 화면의 후보 지역 순번은 분석 우선순위 또는 원인 확정 순위가 아님.
- 고객 A/B/C는 해당 후보에 연결된 **원본 고객 ID별 익명 표시**이며 각 행을 열어 발견/검증일, MOS, SIP 11.REASON, 위치 근거를 확인할 수 있음.
- 전/후 후보 비교는 기존 혼합분석(위치+Cell) 5건과 엄격 위치 기반 7곳의 차이를 다른 정책/입력이라는 경고와 함께 표시. 공간상의 가장 가까운 위치는 동일 원인 확정이 아님.
- 빨간 3px 본부장 요구사항 강조는 상단 **본부장 요구 강조** 버튼으로 켜고 끄는 opt-in; 기본 서비스 화면에서는 해제.
- 모바일 작은 화면에서 필터 버튼 묶음이 오른쪽으로 넘치던 문제(390px에서 페이지 452px이던 결함) 개선 2안 범위에서 수정.
