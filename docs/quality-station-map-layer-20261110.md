## 지도별 기지국 표시
- 개선후보 분석/대안모델: 후보 표시 원 내부 기본, 주변 500m 확장, 숨김; LTE/5G/모두. 같은 좌표·같은 RAT 셀을 하나의 타워 아이콘으로 묶음. 클릭 시 RU/Cell/PCI 목록 및 MDT 연결 RSRP 확인
- 후보 선택 중 포함된 삼각 측량 근사점의 실제 3개 사이트 입력 기지국은 주황색 강조 및 기지국→근사점 점선 연결. 기지국이 후보 원 밖에 있어도 입력 근거는 별도 노출. 점선은 거리/계산 근거 관계일 뿐 이동/전파 경로가 아님
- 품질 현황: GPS/삼각 측량 근사에 이어 '측위 기지국' 토글. 근사 계산에 실제 사용한 MDT RU·Cell 위치만, BYE 단독 참고 위치는 제외
- 고객·통화 지도: 기존 Serving/Neighbor 및 BYE 연계 정보를 유지하면서 공통 타워 SVG 적용. 정확한 통화 관련 기지국만 표시
- 통화 상세 팝업: 3개 사이트 근사 계산 RU·Cell과 별도 BYE 기지국 참고를 공통 타워 아이콘으로 표시
- 기지국·PCI 검색: 선택한 LTE/5G RU 위치에 같은 타워 아이콘 표시
- 동일 좌표의 여러 셀은 툴팁/팝업에서 별도 목록을 확인. 등록 기지국 위치 ≠ 단말 위치/커버리지 확정
- 주파수, Azimuth, 실제 전파 커버리지는 등록값이 부족해 임의로 만들어 그리지 않음
- 기존 DBSCAN/대안 모델의 후보, 순위, 검증 건수는 변경하지 않음
