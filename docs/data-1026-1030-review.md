## 연결 알고리즘과 보수적 해석

- **MOS:** SIP CDR 원본 RTCP MOS(v5)만 사용합니다. RSRP로 MOS를 재산출하지 않으며 미평가는 미평가로 남깁니다.
- **CDR–MDT 연결:** 서비스계약 ID + 통화 시작시각 ±30초로 후보를 찾되, CDR/MDT 간 **서로 유일한 1:1 후보**만 연결합니다. 서로 다른 날 사이의 매칭은 금지합니다.
- **연계 진단:** CDR–MDT 상호 유일 연결 4,290통화, 후보가 모호한 통화 638건, 연계되지 않은 통화 179,304건. 541,811 MDT 원본 행 가운데 적합한 이벤트로 538,762건이 구문 분석됐다고 해서 모든 CDR에 MDT가 연계된다는 뜻은 아닙니다.
- **기지국 목록:** `수도권_LTE_261103.xlsx`의 RU+Cell 정확 매칭 우선. 중복 Cell ID 단독 연결은 제한합니다.
- **종료 대표 위치:** 원본 GNSS → 기본 검토 조건을 통과한 3사이트 이상 위치 추정 → 유일하게 확인되는 BYE Cell 기지국 좌표 순서. BYE Cell 좌표는 **UE 실측 위치가 아닌 접속 기지국 위치**입니다. 지도·행정동 기준 위치는 MOS 저하가 실제 발생한 지점으로 단정할 수 없습니다.
- **공간 품질:** MDT 데이터가 품질·지역별로 균일하게 수집됐다는 근거가 없으므로 이 지도만으로 행정동별 전체 불량률을 산출하지 않습니다.
