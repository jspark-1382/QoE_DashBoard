# 수도권 LTE 261103 기지국 인벤토리 매칭 및 MDT 위치추정 재검토

검토일: 2026-11-03. 대상: 2026-10-30 SIP CDR 37,731건, VoLTE MDT 부분표본. **MOS 점수는 CDR 원본 그대로 유지.**
기지국 입력: data/BaseStation/수도권_LTE_261103.xlsx (기존 BaseStation_new.txt 보조).
실제 빌드 결과: public/voice-1030.json, public/analyst-overview/MDT/2026-10-30.json.
검증 로그: outputs/lte261103-build.log, outputs/lte261103-overview.log, outputs/voice-1030-quality-report.json.

## 1. 신규 LTE 인벤토리 검증

원본 파일은 Sheet1, 87,562 데이터 행, cell_id / LTERU_ID / latitude / longitude 네 컬럼입니다.
유효 87,322행, 좌표 또는 필수 키 이상 240행. 개별 cell_id는 60,414개이고, 그중 21,608개는 여러 RU에 반복됩니다. 18,424개 cell_id는 여러 좌표와도 연결됩니다.

**cell_id 단독으로 UE 위치 또는 기지국을 확정하는 매칭은 금지.**
LTERU_ID와 cell_id의 정확한 쌍으로 조회해 유일한 좌표일 때만 수용합니다.
새 자료에는 RSRP, EARFCN/주파수, PCI, 송신출력, 안테나 방위각, 정확도 정보가 없습니다.
일치되지 않는 RU+CellID는 기존 999개 RU 기반 Master의 유일 식별이 있을 때만 보조 근거로 사용합니다.
MDT의 RU+CellID 정확 매칭은 본 자료에 요청된 고유 쌍 170개 중 137개입니다.
실제 MDT 3,721개 샘플 중 3,189개가 정확한 RU+CellID로 일치했고, 그중 RSRP가 있는 것은 1,988개입니다.
기존 RU 목록과 공통으로 확인되는 108개의 좌표 차이는 전부 0m입니다.

## 2. MDT 없는 CDR의 3변 측량 불가 및 BYE Cell 기지국 대체 매핑

CDR에는 동시성 있는 3기지국 RSRP/거리 정보가 없으므로 MDT 미연계 통화에 다변측량을 수행하지 않습니다. 대신 CDR END Cell ID를 신규 수도권 LTE 261103 인벤토리의 단일 기지국 RU 좌표에 엄격히 매핑합니다.

전체 CDR 37,731건 중 종료 Cell ID가 단일 RU/유효 좌표에 매핑되는 통화 7,179건, 여러 RU의 중복 셀로 모호한 통화 23,483건, 목록에서 찾을 수 없는 통화 7,069건입니다. 기존 GNSS/3사이트 위치가 더 우선인 10건을 제외하고 7,169건의 BYE Cell 기지국 대체 위치를 사용합니다. 동일 좌표를 가진 서로 다른 RU라도 단일 기지국 ID로 확정하지 못하면 매핑하지 않습니다.

**BYE Cell 좌표는 접속 기지국 사이트 주소이며 단말 실측/추정 위치를 의미하지 않습니다.** MOS 전체 점수·실제 MOS 저하 장소 역시 바뀌지 않습니다. 행정동 순위에서 기지국 기준 지역과 GNSS/3사이트 근거 수를 분리해 보여줍니다.

| 근거 | 전체 CDR 위치 연결 | 저MOS 위치 연결 |
|---|---:|---:|
| GNSS | 28 | 28 |
| 기본 검토 조건 통과 3사이트 이상 다변측량 | 21 | 21 |
| BYE Cell 기지국 위치 (UE 위치 아님) | 7,169 | 44 |
| 합계 | 7,218 | 93 |
| 위치 미확인 | 30,513 | 195 |

보통 MOS 통화 위치 연결 91, 양호 통화 5,111, MOS 미평가 통화 1,923입니다. 이전 저MOS 부분표본 위치 91건과 전체 CDR 위치 연결 7,218건은 분모가 다릅니다.

## 3. MDT 기반 3사이트 이상 위치추정

기존 비선형 가중 최소제곱 엔진(estimateAdaptive, solveWeighted)을 사용합니다.
- 동일 물리 위치의 다중 Cell은 20m 이내 완전연결 조건으로 한 사이트에 묶어 독립 사이트 수를 부풀리지 않습니다.
- 동일 통화에서 시각 차이 5/10/20/30/60초의 순차적 시간창으로 유효 RSRP를 수집합니다.
- 독립 사이트가 3개 이상이면 log-distance 기반 다변측량; 2개이면 가중 근사 위치(3변 측량으로 표시하지 않음); 1개이면 단말 위치를 표시하지 않습니다.
- GNSS 관측이 있으면 최우선이며, 통화 종료(CDR END TIME, SIP BYE 대용) 60초 이내 마지막 GNSS 또는 무선 위치 후보 하나를 대표점으로 선택합니다. 종료 이후 1초까지의 소스 시각 차는 허용합니다.
- 단말 경로의 원본 GNSS/MDT 샘플은 삭제하지 않습니다.

### 위치 추정 모델 품질 검토

기존 모델의 3사이트 이상 추정은 동일 통화 내 시간창(5~60초)에 기반합니다. 기본 검토 기준은 geometry≥0.02, 모델상 불확실성≤3,000m, 모델 점수≥30, 잔차≤800m를 동시에 만족하는지 여부입니다. 종료 60초 이내의 후보 중 이 조건을 만족하는 마지막 추정점을 선택하므로 새 정책에서 21통화가 다변측량 근거로 채택됐습니다. 단 3사이트 검토 통과는 실제 위치 오차 보증이 아닙니다. 2사이트 근사 및 모델 경고 추정은 단말 좌표로 사용하지 않고 BYE 기지국 대체 위치의 근거가 될 수 있는지 확인합니다.

## 4. 알고리즘 검토 결과와 한계

1. **셀 ID 중복:** 원래 CellID 단독 결합은 잘못된 좌표 생성 위험이 큼. 새 RU+CellID 유일 매칭으로 해결.
2. **RSRP→거리의 지역 외 보정:** 현재 참조 모델 P0=-83.7dBm@100m, 경로손실 지수 n=0.75, 최소 20m·최대 1,500m이며 종전 자료 경험식입니다. 수도권 새 RU/Cell 측정에 재교정·홀드아웃 검증 없이 정확도를 단정할 수 없습니다.
3. **시간적 비동시성:** 인접 시간창의 서로 다른 사이트 RSRP를 가중한 위치추정이므로 완전 동시 3기지국 측정과 다릅니다. 윈도 폭 및 실제 deltaTimeSec 근거를 유지해야 합니다.
4. **가깝거나 거의 일직선인 기지국:** 사이트 수 3개만으로 충분하지 않습니다. geometry와 residual, 모델 불확실성으로 재검토 대상을 구분합니다.
5. **2사이트 추정:** 방향 결정이 불충분하므로 삼변 측량으로 명명하지 않습니다.
6. **GNSS 우선 및 종료 기준:** MOS는 통화 단위 수치이고 종료 위치는 MOS 저하 순간을 뜻하지 않습니다.
7. **데이터 선택편향:** MDT가 저MOS 중심 부분표본이므로 지역별 전체 불량률을 계산하지 않습니다. 순위는 종료 대표 좌표가 있는 저MOS 통화 건수만 사용합니다.

## 5. 추가 데이터 확보 시 우선순위

- MDT가 없는 CDR의 3변 측량에는 실제 동시성 있는 3개 이상 Cell/RU별 RSRP와 측정시각이 필수입니다. 없을 때 유일한 BYE Cell 기지국을 찾으면 기지국 위치로 대체하고, 모호하면 위치 미확인으로 둡니다.
- 신규 기지국 자료의 방향, EIRP/RS power, 주파수/EARFCN, 안테나 고도, 셀·PCI 정보 확보.
- 독립 GNSS 보유 통화를 훈련·검증으로 분리해 수도권 RSRP 거리식 재보정, 위치오차 p50/p90, 지역별 오차, RSRP·시간창별 신뢰도 보정 검증.
- 모호한 CDR·MDT 연결과 종료 셀 소유 측정 방향의 정확성을 현장 기준으로 확인.
