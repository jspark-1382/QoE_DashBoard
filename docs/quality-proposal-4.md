## CDR 종료(BYE 시점 대용) 위치 및 기지국 대체 매핑 — 2026-11-03

동일한 원칙을 모든 CDR 통화에 적용합니다: (1) 종료 직전 유효 GNSS 관측 (2) 3개 이상 독립 기지국을 사용하고 기하/잔차/모델 불확실성 조건을 통과한 위치 추정 (3) 신규 LTE 기지국 목록에서 단일 RU/좌표로 식별되는 BYE Cell 기지국 좌표 (4) 근거가 없으면 위치 미확인.

실제 SIP BYE 메시지 시각이 별도로 확인되지 않으므로 CDR END TIME을 종료 기준으로 사용합니다. GNSS/다변측량에는 종료 60초 이내, 종료 이후 1초의 시간 오차 허용 범위를 적용합니다. 2사이트 근사 및 조건 미통과 다변측량은 단말 좌표로 사용하지 않고 BYE Cell 대체 매핑 대상으로 처리합니다.

**BYE Cell 좌표는 단말 위치가 아닌 접속 기지국 위치입니다.** BYE Cell이 여러 RU에서 재사용되거나 기지국 인벤토리에 없다면 매핑하지 않습니다. 해당 기지국이 속하는 행정동은 실제 UE 위치 행정동과 다를 수 있습니다.

실제 2026-10-30 재계산 결과: 전체 37,731통화 중 7,218통화 위치 연결 (GNSS 28, 검토 조건 통과 3사이트 이상 21, BYE Cell 기지국 7,169). 저품질 288통화 가운데 93통화 위치 연결 (GNSS 28, 3사이트 이상 21, BYE Cell 44). 위치 미확인 30,513통화. 보통 위치 연결 91, 양호 위치 연결 5,111 (그 외 미평가 1,923). 통화당 대표 위치 및 행정동 최대 1곳. MOS 점수와 CDR 원본 및 고객 이동경로는 변경하지 않습니다.

지도는 GNSS·3사이트 추정·BYE Cell 기지국 위치를 별도로 표시하고, 상세 통화/CSV에는 BYE Cell ID 및 RU와 위치 근거를 기록합니다. 지역별 전체 통화 불량률은 산출하지 않습니다.

## 원본 품질현황과 동일한 MOS 분포 필터

MOS 도넛 색상 호 또는 오른쪽의 **불량·보통·양호** 행을 클릭하면 해당 MOS(v5) 등급의 **전체 SIP CDR 통화**를 하단 통화 상세 목록에서 조사합니다. 동일 등급을 다시 클릭하거나 상단 선택 배지 ×/초기화를 누르면 해제됩니다. 데이터가 있는 시간대와 고객 유형 선택은 결합됩니다.

- 선택 없을 때: GNSS/3사이트 추정/BYE 기지국 위치를 연결할 수 있는 저MOS 통화를 표시합니다.
- 불량 선택: MOS 3.0 미만 **288건**을 전체 CDR에서 필터링하며, 위치가 없는 통화도 표에 포함합니다. 지도에는 GNSS/3사이트 추정/BYE 기지국으로 위치가 연결된 저MOS 93건을 표시합니다.
- 보통 선택: MOS 3.0 이상 3.5 미만 **442건**을 전체 CDR에서 조회합니다.
- 양호 선택: MOS 3.5 이상 **25,958건**을 전체 CDR에서 조회합니다.
- 보통과 양호도 각 통화에 직접 연결된 BYE Cell 기지국 위치를 지도에 표시합니다. 저MOS 위치를 다른 MOS 등급에 재사용하지 않습니다. 기지국 좌표는 UE 위치가 아닙니다.
- MOS 분포·KPI는 전체 선택 시간 범위에 대한 집계로 유지하며, 선택한 구간의 조사 대상은 통화 표·필터 배지에 반영합니다. 미평가 11,043건은 품질 등급에서 제외합니다.

저품질 KPI에는 **전체 37,731건 대비 288건 = 0.8%**를 건수 옆에 배치하고, **유효 MOS 26,688건 대비 = 1.1%**를 아래에 별도로 표시합니다. 서로 다른 분모를 혼동하지 않도록 텍스트로 구분합니다.

통화 상세는 화면에 표시되는 CDR 파티션부터 지연 로딩합니다. RTP 손실·Jitter의 원본 단위는 검증 전이므로 단위를 확정해 표시하지 않습니다. 익명 고객 ID를 사용하며 CSV는 사용자 클릭으로만 저장됩니다. 개인정보가 포함된 JSON은 외부에 배포하지 않습니다.

## 2026-11-03 선택 통화 분석 팝업 내 미니 지도

선택한 통화 분석 팝업에 해당 CDR 통화 한 건의 종료 대표 위치 지도를 추가했습니다. model.markerByCall.get(selected.id)로 기존 검증된 단일 위치만 전달하며 전체 고객 이동경로 또는 행정동 중심점을 복사하지 않습니다. GNSS, 품질조건 통과 3사이트 이상 추정, BYE Cell 기지국의 세 원천을 마커와 텍스트로 구분합니다. BYE Cell 기지국은 UE 위치가 아니며, GNSS 및 무선 추정도 정확한 MOS 악화 시점을 나타내지 않습니다. 매핑할 수 없는 CDR 통화는 빈 지도가 아니라 위치 미확인 메시지로 처리합니다. 기존 품질현황 및 통화별 MOS 집계는 변경하지 않습니다.
