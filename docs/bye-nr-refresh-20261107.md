# 현황 BYE 기지국의 5G 반영

이 문서는 5G 반영 당시의 검증 기록이다. 이후 사용자 요청으로 복수 RU의 표시 정책을 [MDT 우선·첫 후보 선택](bye-site-selection-20261107.md)으로 변경했다.

기지국 검색 목록만 갱신되고 현황용 BYE 생성 경로가 LTE 인벤토리만 읽던 누락을 수정했다. 원본 SIP CDR에는 실제 VoNR 통화가 있으며, LTE MDT 표본의 통신 방식으로 CDR 종료 Cell의 통신 방식을 판단하면 안 된다.

- 선택한 BYE Cell과 같은 메시지의 PANI에서 `endRat`을 보존한다. BYE Cell이 없을 때만 200OK Cell과 그 메시지의 PANI를 사용한다.
- LTE/NR이 명시되면 해당 인벤토리에서 Cell의 RU·좌표가 유일해야 한다. 통신 방식이 미상이면 두 목록 전체에서 유일해야 한다. 중복·좌표 충돌은 임의로 매칭하지 않는다.
- GNSS·검토 가능한 무선 위치를 우선하며 BYE는 등록 기지국 참고 좌표다. 단말의 측정 위치나 MOS 저하 지점으로 표시하지 않는다.
- NR 파일 해시를 원본 revision에 포함하고 현황·3사이트·조사 후보·무선 참고·PCI 목록을 같은 revision으로 재생성했다.
- 통화 상세 지도와 PCI 표도 LTE/NR 식별자를 구분한다. NR 등록 PCI는 0~1007로 검증하며, 없는 관측 PCI는 만들지 않는다.

## 검증 결과

5일치 184,232통화와 85,302개 상세 파티션의 원본 통화·고객·MOS·MDT 샘플을 대조했다. 기존 GNSS/검토 위치 535개와 기존 위치 좌표는 모두 유지했다. NR BYE 위치 9,345건이 추가됐고 그중 저품질 통화는 71건이다.

10월 30일 전체 BYE 위치는 7,166→9,071통화, 저품질 BYE 필터는 49→63통화다. 기본 지도는 GNSS·3사이트 우선 적용으로 BYE44→58, 전체 위치97→111통화다. 전체 통화37,731건과 저품질288건은 변하지 않았다.

새 revision은 `1112f92fe0d4d82d3803`이다. 단계별 검증·원본 해시·교체 목록은 `.tools/bye-refresh-20261106/stage-verification.json`에 보관한다. 서버 재시작과 현황/통화 상세의 실제 지도·PCI 표시를 확인했다. 인벤토리 파일 교체나 검색 목록 생성만으로 BYE가 자동 재계산되지는 않으므로 [인벤토리 전체 갱신 순서](station-pci-refresh-20261106.md)를 따른다.
