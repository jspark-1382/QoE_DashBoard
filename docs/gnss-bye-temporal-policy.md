# 최근 GNSS + MDT + BYE Cell 위치 참고 정책 (2026-11-04)

적용: MDT_New 2026-10-26~30일 SIP CDR/MDT 및 data/BaseStation/수도권_LTE_261103.xlsx.

## 구현 규칙

1. 동일 통화 ID의 관측 시각 이전 실제 GNSS만 사용한다. 미래 관측과 다른 통화의 GNSS는 제외한다.
2. 종료 CDR END 또는 후속 MDT 관측 전 최대 180초 이내 최신 GNSS를 기준점으로 사용한다. CDR END는 실제 BYE 패킷 시각과 다를 수 있다.
3. 위치 가정 범위 반경(m) = 250 + (120 / 3.6) × 경과초. 120km/h 속도와 250m는 검증된 실제 움직임/정확도가 아닌 보수적인 시각화 가정이다.
4. 3사이트 무선 추정이 기존 위치 신뢰성 검토를 통과하더라도 이전 GNSS 이동 가능 범위를 벗어나면 지도 좌표로 채택하지 않는다. 원본 모델 후보/진단은 보존한다.
5. 원본 GNSS 좌표를 이후 MDT나 BYE 시각의 실측 좌표로 복제하지 않는다. 지도에는 기존 GNSS 실측 점, 가정 이동 가능 영역을 각각 표시한다.
6. BYE Cell은 전체 기지국 목록에서 RU가 유일하게 확인된 경우에만 별도의 종료 기지국 좌표와 관계선으로 표시한다. 그 관계선은 단말 이동경로가 아니다.
7. 행정동 위치 데이터는 마지막 GNSS 관측점을 60~180초 이전이면 gnss-last-known으로 표기한다. 마지막 GNSS 관측 행정동은 단말의 실제 통화 종료 행정동이라는 보증이 없다.
