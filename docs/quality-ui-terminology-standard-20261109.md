# QoE UI 용어 표준화 (2026-11-09)

## 사용자 화면 표기
- `GNSS` → **GPS**: 지도 범례, 통화 상세, 표, 설명, 분석·시뮬레이터 화면.
- `3사이트 추정`, `3-Site`, `무선 추정`, `3변측량` 등 → **삼각 측량**: 3개 이상 사이트 기반 위치 산정의 화면상 통합 명칭.
- **`MOS` → `QoE`**: 상단 메뉴, 품질 지표, 분포, 시간대 그래프, 고객·통화 상세, 후보 분석, 알고리즘 비교 및 시뮬레이터 사용자 표시 용어.
- **2개 기지국 가중중심**, **BYE Cell 기지국 참고 위치**, **보간 추정**은 별도 산정 방법/근거이므로 같은 항목으로 합치지 않음.

## 데이터·정확도 주의
- 데이터 필드 `gnss`, 정책 키 `strict-3-site-v1`, `GNSS_CDR_ASSOCIATION`, 소스 파일명 및 원본 JSON은 바꾸지 않음.
- 사용자 화면의 GPS는 기존 원본 GNSS 위치 관측 데이터를 가리키는 쉬운 표기임. 신호 원천이 GPS 단일 위성체계라는 검증 결과는 아님.
- 삼각 측량은 화면상 통합 명칭이며, 일부 원본 계산은 **3개 사이트 RSRP 가중중심 기반 대략 위치**임. 진정한 삼각법/삼변측량으로 정확 좌표가 검증되었다는 뜻이 아님.
- 화면의 **QoE 1~5점**은 새로운 측정값이 아니라 기존 **RTCP MOS(v5)** 점수를 그대로 보여주는 명칭 변경임. 품질 판정 기준(불량 3.0 미만, 주의 3.0~3.5 미만, 양호 3.5 이상)과 분모, 원본 값은 보존함.
- `mos`, `mosV5Original`, `qoeBasis='rtcp-mos-v5'` 등의 원본 필드·식별자는 변경하지 않음. 캐시된 원본 보고서의 후보명은 렌더링할 때만 변환함.
- QoE 저하 순간/종료 시점의 실제 고객 좌표, 위치 오차 및 원인 확정을 의미하지 않음.
