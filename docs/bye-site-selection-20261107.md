# BYE 기지국 후보 선택

같은 종료 Cell에 여러 RU가 등록된 경우에도 지도에서 조사할 수 있도록 선택 정책을 변경한다. 사용자 요청에 따라 같은 통화의 MDT 장비 코드로 선택하고, 결정할 수 없으면 원본 기지국 목록의 첫 번째 유효 좌표 후보를 사용한다.

- 종료 RAT가 LTE/NR로 명시되면 해당 목록 안에서만 선택한다.
- 단일 후보는 그대로 사용한다. 복수 후보는 CDR–MDT 연결이 확정된 동일 통화의 종료 Cell·RAT·RU가 일치하는 MDT를 확인한다.
- 종료 30초 전부터 1초 후까지의 최신 관측을 사용한다. 최신 시각에 RU가 충돌하거나 해당 RU의 등록 좌표가 여러 개이면 MDT로 단일 위치를 확정하지 않는다.
- MDT로 선택할 수 없으면 원본 엑셀에 등장한 순서대로 첫 번째 유효 후보를 사용한다. RU 코드의 사전순 정렬이 아니다. 좌표가 없거나 잘못된 행은 건너뛴다.
- `byeSelectionMethod`는 `unique`, `mdt`, `first`이며 후보 수와 MDT 관측 시차를 보존한다. 현황·통화 상세·지도 팝업·CSV에서 선택 근거를 표시한다.
- GNSS·검토 가능한 무선 위치가 우선이며 BYE는 별도 기지국 참고 좌표다. 첫 후보 선택으로 고객의 실측 위치나 저하 발생 지점이 확정된 것은 아니다.
- 개선 후보의 통계 분석에 쓰는 엄격한 유일성 판정 함수는 유지한다. 표시 범위 확대를 분석 신뢰도 향상으로 취급하지 않는다.

선택 정책은 현황 JSON의 `byeSelectionPolicy`에 기록한다. 원본 통화·고객·MOS·MDT 샘플은 변경하지 않고 파생 지도와 관련 자료를 새 revision으로 재생성한다.

검증 기록은 `.tools/bye-selection-20261107/`에 보관한다.
