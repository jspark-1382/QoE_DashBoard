# QoE 분석 플랫폼 — 로컬 실행

이 폴더 안에서만 동작하는 로컬 웹 대시보드입니다. 배포 서비스와 연결되지 않습니다.

## 실행

터미널에서 이 폴더로 이동한 뒤 아래 명령을 실행합니다.

```bash
npm run local
```

브라우저에서 `http://localhost:3000`을 열면 됩니다.

## 데이터 갱신

- 원본 데이터: `data/20260821_행정동.xlsx`
- 화면용 분석 데이터: `public/qoe-data.json`
- 새 Excel을 넣은 뒤 `work/extract_qoe_data.py`를 실행하면 화면용 데이터가 다시 생성됩니다.
- 화면 상단에서는 변환된 QoE JSON을 즉시 불러올 수 있습니다.

VWorld 지도는 화면 상단에 발급받은 API 키를 입력하면 실측 좌표 위에 위성지도가 표시됩니다. 키가 없어도 측정점과 품질 분포는 로컬 배경 위에서 확인할 수 있습니다.
